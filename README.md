# QR Restaurant Ordering System

A Flask-based restaurant ordering system using QR codes for table-based ordering.

## Features
- QR-based table selection
- Digital menu
- Add to cart
- GST billing (5%)
- Special instructions for orders
- Razorpay payment integration
- Admin dashboard
- Admin login protection

## Tech Stack
- Python
- Flask
- SQLite
- HTML / CSS
- Razorpay Payment Gateway

## Project Structure
app.py – Main Flask application  
database.py – Database setup  
templates/ – HTML pages  
static/ – CSS, images, QR codes
